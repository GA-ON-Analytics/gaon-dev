# 인수인계 — 위성 관측이 없는 격자 102개 (2026-08-18)

ML을 돌리는 컴퓨터로 넘어가 이어서 하기 위한 문서.
프론트에서 할 수 있는 임시 조치는 이미 했고(`fix/#104-missing-lst-grids`),
**남은 일은 ML 파이프라인 쪽**이다.

관련 이슈: #104

---

## 1. 무엇이 문제인가

지도에 격자가 아예 없어 회색 구멍으로 보이는 자리가 있다. 격자가 없으니 클릭도 안 된다.
처음 발견된 곳은 강남구 코엑스 옆 `11680_03105`, `11680_03062`.

격자 수가 다르다.

```
backend/data/processed/seoul_grid_dataset.csv   64,676개
public/dashboard/ 격자 파일                      64,574개   ← 102개 적음
```

빠진 102개는 **정확히 `lst_mean`이 빈 격자와 일치**한다(102/102). 우연이 아니다.

---

## 2. 확인한 사실

### 빠진 격자도 값은 멀쩡하다

`11680_03105`의 42개 컬럼 중 **비어 있는 것은 `lst_mean` 하나뿐**이다.

```
building_ratio 0.747512   green_ratio 0.205466   ndvi 0.049384
albedo 0.184              elevation_m 48.558     lst_mean ''        ← 이것만 빔
```

### 관측이 0회다 (이웃은 1~8회)

| 격자 | 관측 횟수 | 지표면온도 |
|---|---|---|
| 11680_03104 (왼쪽) | 8회 | 39.3℃ |
| **11680_03105** | **0회** | 없음 |
| 11680_03106 (오른쪽) | 1회 | 42.2℃ |
| 11680_03062 | **0회** | 없음 |
| 11680_03063 (오른쪽) | 1회 | 38.0℃ |

**강남구 4,162개 중 관측 0회인 격자는 하나도 없다**(최솟값 1회). 즉 `lst_mean`이 비었다는
것은 유효 관측이 0회라는 뜻이고, 평균 낼 값 자체가 없다.

이웃들이 하필 1회씩인 것도 눈여겨볼 만하다 — 이 일대가 QA 마스킹에서 거의 다 걸러졌고
이 두 칸만 0회로 떨어졌다.

### 102개의 공통점은 뚜렷하지 않다

표 형태 데이터만으로는 단일 원인이 안 나온다.

| | 빠진 102개 | 전체 64,676개 |
|---|---|---|
| 알베도 | 0.121 | 0.117 |
| 하천 거리 | 596m | 628m |
| 건물비율(중앙값) | 0.000 | 0.172 |
| 하천 50m 이내 | 25% | 10.8% |

- 알베도가 같다 → **밝은 지붕이 구름으로 오탐된 것은 아니다**
- 하천 50m 이내가 2배 이상 → **물 마스크가 일부는 설명**하지만 전부는 아니다
- 건물비율 중앙값 0 → 상당수는 건물 없는 칸인데, **코엑스 두 칸은 정반대(0.75·0.95)**

원인이 섞여 있다. 코엑스 두 칸은 그중에서도 이례적이다.

## 3. ★ ML에서 해야 할 일

### ① 버리는 단계를 조인보다 뒤로 (이게 더 급하다)

빠진 격자에는 **동 이름·인구·쉼터 값 15개도 없다.** 이건 위성과 무관한데도 없다.
파이프라인 순서 때문이다.

```
lst_mean 계산 → ❌ 빈 행 버림 → 동 이름 → 인구 → 쉼터 거리 → 내보내기
                    ↑ 여기서 102개가 빠져 뒤 계산이 아예 안 돌았다
```

쉼터 거리는 격자 중심에서 가장 가까운 쉼터까지의 **순수 기하 계산**이다. 못 만드는 값이
아니라 **계산을 안 한 값**이다. `dropna(subset=['lst_mean'])` 같은 코드를 조인 뒤로
옮기고, 도형과 나머지 값은 그대로 내보내면 된다.

온도 파생값(`mean_actual_lst`·anomaly·`priority_score`·SHAP)은 비워서 내보내면 되고,
그러면 화면이 '데이터 불완전 격자'로 처리해 이유까지 보여준다. **프론트는 고칠 것이 없다.**

이것만 해도 102개가 전부 살아나고 15개 값이 채워진다.

### ② 관측 0회의 원인 확인

`lst_mean`이 NaN이 되는 지점을 찾아 확인할 것.

- **QA 마스킹 비트** — 구름/그림자/권운 중 무엇이 이 픽셀을 걸렀나. 열적외선 밴드는
  원본 해상도가 거칠어 100m 격자 하나에 유효 픽셀이 몇 개 없고, 코엑스처럼 고층이
  밀집한 곳은 구름 그림자로 오탐되는 경우가 있다
- **최소 관측 조건** — `observations >= N` 같은 문턱이 있는지
- 다른 시기 영상을 넣으면 메워지는지

여기까지 오면 온도까지 살릴 수 있다. 안 되면 ①만으로도 구멍은 사라진다.

## 4. 프론트에서 이미 한 것 (임시 조치)

브랜치 `fix/#104-missing-lst-grids`.

- `scripts/patch-missing-lst-grids.py` — 자리를 **정확히 계산할 수 있는 격자만** 되살린다.
  격자 번호는 한 줄을 따라 1씩 늘고 간격이 정확히 100m라, 좌우 이웃이 같은 줄에 200m
  간격으로 있으면 그 사이가 빠진 칸이다. 되살린 도형이 이웃과 **1mm 오차**로 맞물리는
  것을 확인했다.
- 되살린 것은 **3개뿐**: `11680_03105`·`11680_03062`(강남), `11290_00314`(성북).
  나머지 99개는 줄 끝이라 좌우 이웃이 다른 줄에 있어 **자리를 추정해야 한다.** 추정해서
  그리면 지도에 없는 칸을 지어내는 셈이라 손대지 않았다.
- 되살린 격자에는 `lst_observed: false`가 붙고, 상세 패널이 "위성 지표면온도 관측이 없어
  온도·순위·시뮬레이션을 제공하지 않습니다"라고 설명한다. 환경 프로필은 정상 값이라 보여준다.

### ⚠️ 데이터를 새로 받으면 이 패치는 사라진다

격자 파일은 ML 쪽 `dashboard.zip`에서 온다. `install-dashboard-data.py`를 다시 돌리면
덮어써지므로 그 뒤에 한 번 더 실행해야 한다.

```bash
python3 scripts/patch-missing-lst-grids.py
```

**ML에서 ①을 고치면 이 스크립트는 필요 없다.** 그때 지우면 된다.

    if r['lst_mean'] in ('', 'NA', 'nan', 'NaN')}

    'public/dashboard/seoul_grid_100m_map.geojson'))['features']}
